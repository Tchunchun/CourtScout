Usage guidance

  • Primary color: navigation state, buttons, links, and court identifiers.
  • Accent color: focus rings, small highlights, and signature brand moments only.
  • Surfaces: keep tables and cards neutral so match data remains easy to scan.
  • Status colors: reserve green, orange, and red for actual meaning—not decoration.

Palette overview

Each direction preserves high-contrast product surfaces and a restrained tennis accent.
